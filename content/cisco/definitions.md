## Network devices

- **Client**: A client is a network-connected device or application that requests services or resources from another device.
- **Firewall**: A firewall is a network security device or software system that permits or denies traffic according to configured rules.
- **Host**: An endpoint, also called an end host, is a device that communicates over a network rather than providing the infrastructure that connects communicating devices.
- **Host-based firewall**: A host-based firewall is firewall software operating on an individual host to filter traffic entering and leaving that host.
- **Local network**: A local area network is a network that connects devices within a limited geographic area such as an office or building.
- **Network**: A computer network is a set of interconnected devices that communicate and share resources.
- **Network device**: A network infrastructure device is a device that connects end hosts and facilitates communication across a network.
- **Network switch**: A Layer 2 switch is a switch that forwards frames within a local network without performing network-layer routing.
- **Node**: A network node is a device or endpoint that connects to a network and can communicate or share resources over it.
- **Physical network infrastructure**: Network infrastructure is the collection of devices, links, and supporting components that enables network communication and resource sharing.
- **Port number**: A port number is a transport-layer identifier ranging from 0 to 65535 that directs network data to a particular application process on a host.
- **Router**: A network device that forwards packets between different networks based on network-layer addressing.
- **Server**: A server is a network-connected device or application that provides services or resources to clients.
- **Wireless router**: A wireless router is a multifunctional network device that combines routing with switching, wireless access, and often firewall functions.

## Cables, connectors, and ports

- **10BASE-T**: 10BASE-T is an Ethernet physical-layer standard that transmits 10 Mbps over two twisted-pair wire pairs.
- **100BASE-T**: 100BASE-T is an Ethernet physical-layer standard that transmits 100 Mbps over two twisted-pair wire pairs.
- **1000BASE-T**: 1000BASE-T is an Ethernet physical-layer standard that transmits 1 Gbps over four twisted-pair wire pairs.
- **10GBASE-T**: 10GBASE-T is an Ethernet physical-layer standard that transmits 10 Gbps over four twisted-pair wire pairs.
- **8P8C connector**: RJ45 is the commonly used name for the modular connector used with Ethernet twisted-pair cabling.
- **Auto MDI-X**: Auto MDI-X is an Ethernet interface feature that automatically adjusts transmit and receive pin assignments to match the connected device.
- **Binary representation**: Binary language is a computer representation system composed of sequences of 0s and 1s that encode data and computational information.
- **Bit**: A bit is the smallest unit of digital information and has one of two possible values, conventionally 0 or 1.
- **Bit per second**: A bit per second is a unit of data transmission rate representing one transmitted bit per second.
- **Buffer**: A fiber-optic buffer is a protective layer that surrounds and contains an optical fiber.
- **Category 5 cable standard**: A Category 5 cable standard specifies performance requirements for a category of twisted-pair network cabling.
- **Cladding**: Cladding is the reflective optical layer surrounding a fiber core that helps keep light traveling through the core.
- **Connector**: A connector is a physical termination that joins a cable to a compatible port or other connection point.
- **Copper cable**: Copper is a conductive metal transmission medium used in wired network cabling.
- **Copper UTP connection**: A copper UTP connection is a wired network connection that carries electrical signals over unshielded twisted-pair copper cabling.
- **Crossover cable**: A crossover cable is a cable whose transmit and receive pin pairs are reversed between its two ends.
- **Electromagnetic interference**: Electromagnetic interference is unwanted electromagnetic energy that disrupts or degrades electrical signal transmission.
- **Ethernet**: Ethernet is a family of wired networking standards defining physical connection characteristics and data formatting for network transmission.
- **Ethernet cable**: An Ethernet cable is a cable used to carry Ethernet network signals between devices.
- **Fiber core**: A fiber core is the thin glass region of an optical fiber through which the light signal travels.
- **Fiber-optic cable**: A fiber-optic cable is a cable that transmits data as light through one or more glass or plastic optical fibers.
- **Gibibit**: A gibibit is a base-2 unit of digital information equal to 1,024 mebibits.
- **Gigabit**: A gigabit is a data quantity of 1,000 megabits and a corresponding unit for network speed.
- **Glass fiber**: Glass fiber is an optical transmission fiber made of glass that guides light signals through the cable.
- **IEEE 802.11**: Wi-Fi is a family of wireless networking technologies based on the IEEE 802.11 standards.
- **Kibibit**: A kibibit is a base-2 unit of digital information equal to 1,024 bits.
- **Kilobit**: A kilobit is a data quantity of 1,000 bits and a corresponding unit for network speed.
- **Laser transmitter**: A laser transmitter is an optical transmitter that uses a laser to send focused light through fiber.
- **LED transmitter**: An LED transmitter is an optical transmitter that uses a light-emitting diode to send light through fiber.
- **Light signal**: A light signal is an optical signal that represents transmitted data through variations in light.
- **Maximum cable length**: Maximum cable length is the greatest cable distance supported for a network connection while maintaining specified operation or performance.
- **Mebibit**: A mebibit is a base-2 unit of digital information equal to 1,024 kibibits.
- **Megabit**: A megabit is a data quantity of 1,000 kilobits and a corresponding unit for network speed.
- **Multimode fiber**: Multimode fiber is optical fiber that carries multiple propagation modes and is generally used for shorter-distance links.
- **Network speed**: Network speed is the rate at which data can be transmitted over a network connection.
- **Outer jacket**: An outer jacket is the external protective layer surrounding a fiber-optic cable.
- **Port number**: A port number is a transport-layer identifier ranging from 0 to 65535 that directs network data to a particular application process on a host.
- **Receive pin pair**: A receive pin pair is the pair of connector contacts an Ethernet device uses to accept data.
- **Receiver**: A receiver is a component that accepts a signal from a communication medium.
- **SFP port**: An SFP port is a device port that accepts a Small Form-factor Pluggable transceiver for a network connection.
- **SFP transceiver**: An SFP transceiver is a modular small-form-factor pluggable device that converts between electrical signals and optical or other network signals.
- **Shielded twisted pair cable**: A shielded twisted pair cable is a cable containing twisted wire pairs enclosed by a metallic shield.
- **Signal attenuation**: Signal attenuation is the reduction in signal strength as a signal travels through a transmission medium.
- **Single-mode fiber**: Single-mode fiber is optical fiber designed to carry a single propagation mode over relatively long distances with low dispersion.
- **Straight-through cable**: A straight-through cable is a cable whose corresponding pin pairs connect to the same pin pairs at both ends.
- **Tebibit**: A tebibit is a base-2 unit of digital information equal to 1,024 gibibits.
- **Terabit**: A terabit is a unit of digital information equal to 1,000,000,000,000 bits or 1,000 gigabits.
- **Transmit pin pair**: A transmit pin pair is the pair of connector contacts an Ethernet device uses to send data.
- **Transmitter**: A transmitter is a component that sends a signal into a communication medium.
- **Twisted pair**: A twisted pair is a cable construction in which two conductors are helically twisted together to reduce electromagnetic interference.
- **Wire pair**: A wire pair is two conductors in a network cable that together form an electrical transmission circuit.

## TCP/IP model

- **Adjacent-layer interaction**: An adjacent-layer interaction is communication in which one layer of the TCP/IP model provides a service to the layer directly above it on the same computer.
- **Data link layer**: The data link layer is the network-model layer that provides delivery between adjacent nodes over a shared physical medium.
- **De-encapsulation**: De-encapsulation is the process of inspecting and removing protocol headers and trailers as received data moves up a networking stack.
- **Encapsulation**: Data encapsulation is the process of adding protocol-specific control information as data moves through networking layers.
- **Frame**: A frame is a data-link-layer protocol data unit consisting of a packet combined with a Layer 2 header and trailer.
- **Header**: An IPv4 header is the network-layer protocol header that carries IPv4 addressing and control fields for delivering an IPv4 packet.
- **HTTPS**: HTTPS is a protocol for transferring web resources over HTTP with protection provided by TLS.
- **Internet standard**: An Internet Standard is a formally approved specification for protocols and practices used on the internet.
- **IP address**: An IP address is a network-layer identifier assigned to a host or interface for packet delivery across interconnected networks.
- **IPv4**: An IPv4 address is a 32-bit network-layer address used to identify a source or destination in IPv4 communication.
- **IPv6**: IPv6 is the sixth version of the Internet Protocol, using 128-bit network addresses written in hexadecimal notation.
- **Link layer**: The Link Layer is the four-layer TCP/IP model layer that combines the functions of the physical and data-link layers.
- **Local network**: A local area network is a network that connects devices within a limited geographic area such as an office or building.
- **MAC address**: A MAC address is a 48-bit link-layer address assigned to a network-device port, normally by the device manufacturer, for local hop-to-hop delivery.
- **Network hop**: A hop is one journey of a message from one network node to the next node along its path to a destination.
- **Network layer**: A networking layer is a conceptual division of network communication functions that describes a particular role in data transmission.
- **Network packet**: A packet is a network-layer protocol data unit consisting of a segment combined with a Layer 3 header.
- **Networking model**: A networking model is a framework that organizes the functions required for data to travel from a source to a destination over a network.
- **OSI network model**: The OSI model is a seven-layer conceptual framework for describing the functions involved in network communication.
- **Payload**: A payload is the data carried inside a protocol data unit, excluding that unit's protocol control information.
- **Physical layer**: The Physical Layer is a networking model layer that defines the transmission of raw signals and bits over a physical medium.
- **Physical medium**: A physical medium is the tangible or electromagnetic transmission path over which network data is sent.
- **Port number**: A port number is a transport-layer identifier ranging from 0 to 65535 that directs network data to a particular application process on a host.
- **Protocol**: A protocol is a defined set of rules and procedures that governs communication between networked devices or applications.
- **Protocol data unit**: A protocol data unit is a unit of data consisting of a protocol payload together with the control information added at a networking layer.
- **RFC**: An RFC is a published technical document that specifies, discusses, or records internet protocols and related standards.
- **Same-layer interaction**: A same-layer interaction is communication between corresponding layers of the TCP/IP model on different computers.
- **Segment**: A network segment is a connection linking two or more routers.
- **TCP**: Transmission Control Protocol is a transport-layer protocol that provides reliable, connection-oriented delivery with mechanisms for detecting and recovering from lost data.
- **TCP/IP protocol suite**: The TCP/IP model is a layered conceptual framework that describes how network communication functions across application, transport, network, data-link, and physical layers.
- **Trailer**: An Ethernet trailer is supplemental data placed at the end of an Ethernet frame, including the FCS field for error detection.
- **Transport layer**: The transport layer is the network-model layer that delivers data to a specific application process on a destination host.
- **UDP**: User Datagram Protocol is a transport-layer protocol that sends datagrams without guaranteeing delivery of every message.
- **Vendor-neutral model**: A vendor-neutral model is a networking model or protocol framework designed to operate across products from different vendors.
